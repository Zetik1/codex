# Codex

Учебный мультиарендный каркас базы знаний с изоляцией арендаторов
и безопасными плагинами внутри своей библиотеки.

Не SaaS-платформа и не маркетплейс — учебный проект и портфолио.

## Что это

Веб-сервис, где человек собирает собственную базу знаний из **блоков**
(заголовок, текст, галерея, инфобокс, связи и т.д.), а не из сплошного
Markdown-файла.

У статьи две части:

- **поля** — короткие значения по схеме типа статьи (`ArticleType.fields_schema`);
- **блоки** — упорядоченный список содержимого.

Структуру данных задаёт пользователь (свои типы статей и поля), а не
разработчик платформы. Код приложения при этом не меняется.

## Модель

Один экземпляр приложения обслуживает много библиотек. У каждой строки
почти в каждой таблице есть `library_id`. Любой запрос обязан фильтроваться
по нему: забыл фильтр — пользователь видит чужие данные. Это проверяется
тестами с первого дня.

До этапа с пользователями `library_id` — заглушка (константа `1` без FK).

## Стек

| Слой | Технология |
|---|---|
| Язык | Python 3.14 (запасной вариант — 3.13) |
| API | FastAPI |
| ORM / миграции | SQLAlchemy 2.0, Alembic |
| Валидация | Pydantic v2 |
| БД | SQLite → PostgreSQL |
| UI | Jinja2 + HTMX |
| Редактор блоков | Editor.js |
| Плагины | Pyodide (Wasm) + Web Worker + iframe с отдельным origin |
| Прочее | nh3, Pillow, argon2-cffi, pytest, Docker, ruff |

Без React, Vue, TypeScript, Kafka, микросервисов, Celery, Redis, Django и LLM.

## Плагины (кратко)

Пользователь пишет настоящий Python. Код исполняется **в браузере посетителя**,
не на сервере.

Защита:

- отдельный origin для песочницы (`sandbox.localhost` / второй порт / поддомен);
- результат рисует **только iframe** (родитель не делает `innerHTML` с разметкой плагина);
- данные в песочницу — только через `postMessage` (без cookie и токенов в iframe);
- проверка `event.origin` / `targetOrigin`;
- CSP; на хосте песочницы нет API;
- манифест прав + выдача данных сервером по схеме полей;
- таймаут + `worker.terminate()`.

Плагины версии 1 работают **только внутри библиотеки автора**.
Маркетплейс, модерация «для всех» и публикация в чужие библиотеки — out of scope.

## Чего проект не делает

- не хостит видео;
- не соцсеть;
- не исполняет пользовательский код на сервере;
- не офисный редактор со свободной вёрсткой;
- не готовится к продакшену с живыми пользователями.

Подробности — в [`docs/BRIEF.md`](docs/BRIEF.md). Задачи — в [`docs/ROADMAP.md`](docs/ROADMAP.md).
